Here you find  open software for neuroscience developed at the [Brain Research Institute of University of Bremen](https://www.uni-bremen.de/en/brain-research-institute). Notable projects include:
 
- **[event-triggered-analysis](https://github.com/brain-bremen/event-triggered-analysis)**: Open Ephys plugins for event-triggered analysis, including averaging as well as power and coherence spectra workflows.
- **[amplitude-estimator](https://github.com/brain-bremen/amplitude-estimator)**: An Open Ephys plugin for amplitude estimation via rectification (RMS) to support signal quantification pipelines.
- **[dh5io](https://github.com/brain-bremen/dh5io)**: Python tools for reading and writing the DAQ-HDF5 file format for electrophysiology used in-house since 2005.
- **[XClock](https://github.com/brain-bremen/XClock)**: Tools for synchronizing multiple Xperimental Clocks at different rates
